# ai-ml-daily
Dataset: Student Performance Dataset (395 rows, 33 columns)
Source: Kaggle, uploaded by Dev Ansodariya, https://www.kaggle.com/datasets/devansodariya/student-performance-data/data
Original source:  "not stated"
License: CC0: Public Domaine

Problem: Predict whether a student passes (G3 >= 10) using background
and habit columns, dropping G1 and G2 to avoid data leakage.

Metric: F1-score for the fail class, plus accuracy compared with the
67% baseline (always predicting "pass").
